Core Features

Everything you need to run deliveries smarter

Hands-free control

Drivers can update shipment statuses, check ETAs, and request navigation purely through voice commands, ensuring safety on the road.

Biometric security

Powered by SpeechBrain's ECAPA-TDNN model, our AI verifies the driver's unique voice profile before confirming critical delivery updates.

Real-time oversight

Administrators get a bird's-eye view of all active drivers, deliveries, and AI interactions from a centralized, live-updating dashboard.

Live GPS tracking

Track every driver's real-time location on an interactive Leaflet map. Monitor route adherence and ETA accuracy for each shipment.

AI intent recognition

Natural language commands are understood and executed automatically. Six built-in intents cover every common logistics scenario.

Instant notifications

Admins can push real-time alerts directly to individual drivers. Changes sync instantly via Firebase without needing a page refresh.
